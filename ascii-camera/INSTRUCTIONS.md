<p align="center">
    <b>Your webcam becomes ASCII art in real time. That's it.</b>
</p>

---

**Change Current Folder:**
```
cd ascii-camera
```

**Install:**
```
pip install -r requirements.txt
```

**Run:**
```
python convert.py
```

Your webcam opens immediately. Press `Ctrl+C` to stop.

Use a monospace font (Consolas, Courier New, JetBrains Mono) and a small terminal font size. 

**The smaller the font, the more detail you get.**
